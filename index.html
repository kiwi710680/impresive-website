The shared architecture

Evidence preparation, in five chapters

IMPRESIVE starts from the decision question, not from a database. Whether a source can answer that question is settled before any implementation route is chosen.

  1. 01FrameDecision need → common questions
  2. 02AssessCharacterisation → fit for purpose
  3. 03ImplementQuestion, protocol, or common data model
  4. 04InterpretPooling, diagnostics, transportability
  5. 05IntegrateEvidence integration → decision

A source that falls short is not forced through the pipeline. The characterisation becomes the result, and it defines what the next round has to change.
